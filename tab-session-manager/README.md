# Tab Session Manager

This folder contains planning docs for a Chrome/Edge browser extension inspired by Tabs Outliner.

## Files
- `spec.md` — product spec / SpecKit-style requirements document

## Project idea
A tree-based browser session manager that combines:
- tab management
- session management
- selective restore after close/crash

## Current status
Planning/spec stage only. No implementation files yet.
